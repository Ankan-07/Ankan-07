- I value **fundamentals over frameworks** — understanding the problem before reaching for a library
- My projects reflect **learning through failure** — if it never broke, I probably didn't push it far enough
- I care about **clean design and real debugging**, not demos that only survive a happy path
- I write code meant to run in production, not just pass a portfolio review
